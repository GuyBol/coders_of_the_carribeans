# Simulator Instructions

## Purpose

- Create a simulator to play games locally.
- Prepare for a game where the referee is unavailable: never try to find a referee online.
- Build the simulator from the game rules.

## Performance

- Keep the simulator efficient and make it run as fast as possible.

## Bot Integration

- Allow locally developed bots from the `bots` folder to play against one another.
- Compute the scores and report the winner at the end of each game.

## Validation

- Match the real simulator's outcomes **exactly**.
- Fetch games from the CodinGame arena and replay them locally to verify that the simulator produces **exactly the same output**.
- Analyze and fix every difference.

## Documentation

- Generate and maintain a `README.md` documenting the simulator and explaining how to set it up, run games with local bots, and validate it against captured games.
