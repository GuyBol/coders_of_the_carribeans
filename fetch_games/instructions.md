# Fetch Games Instructions

## Game Retrieval

- Create a script that fetches games from the CodinGame arena.
- Investigate the undocumented API used to retrieve games.
- Support fetching games for a specified player.

## Player Lookup

- Ideally, retrieve the player ID or agent ID for a specified player.
- Support looking up both the user's own account and players from the leaderboard.
- The goal is to retrieve games played by the best players.

## Storage

- Save fetched games in a dedicated repository.
- Include metadata identifying the players in each game.

## Documentation

- Write a README with basic documentation and usage instructions.
