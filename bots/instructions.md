# Bot Instructions

This directory contains the implemented bots.

## Folder Structure

- Create one folder per bot type.
- For example, `wood_bot` contains the bot used to compete in the Wood league.
- Create a new bot only when explicitly requested.

## Input Parsing

- `boilerplate.cpp` contains the base code for parsing game inputs.

## Documentation

- Keep a Markdown file alongside each bot source file explaining how the bot works.
