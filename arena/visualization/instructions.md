# Arena Visualization

## Purpose

- Display games played in the arena, offering an experience similar to the CodinGame website.
- Simple graphics are sufficient; highly polished graphics are not required.

## Game Support

- Create a dedicated folder for Coders of the Caribbean visualization.
- Allow for support for other games in the future.

## Hosting

- Choose how to expose the UI. A small web server is one option, but other technologies are acceptable.

## Playback

- Allow users to view games, play and pause replays, and navigate to a particular frame.
